# Lingara examples

Runnable examples built on Lingara's released packages, filed by what you
build:

- `integrations/` — a server that calls the Lingara API or receives its
  webhooks.
- `apps/` — an app that renders cards inside Lingara.
- `games/` — Lingara inside a game engine.

Every example installs only what you could install yourself: Lingara's
packages from their public registries, at exactly the version listed below.
Clone this repository, open an example and follow its README.

## Checking an example

    make check-publishable                     # the index and every example's dependencies
    make build-checker
    make build-example test-example DIR=<path> # one example, with its language's toolchain
